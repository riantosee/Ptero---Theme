SYSTEM ARCHITECTURE WARNING

Are Legacy Pterodactyl Versions (v1.x) Supported?

NO — PTERODACTYL v1.x (v1.11.x & OLDER) IS NOT SUPPORTED.
All MIRAINOVA themes are engineered exclusively for the Pterodactyl v2 Extension & Theme System (.pteroext packages and Tailwind CSS v4 tokens). Legacy v1.x panels rely on monolithic Blade templates + Laravel Mix/Webpack and lack the php artisan p:extension:install loader and hot-swappable theme engine.

Pterodactyl v2.0.0-beta.2+ ✓ FULLY SUPPORTED (NATIVE)
Pterodactyl v2.x Dev Branch ✓ FULLY SUPPORTED
Pterodactyl v1.11.x (Legacy) ✕ NOT SUPPORTED (Incompatible DOM)
Blueprint v1 Framework ✕ INCOMPATIBLE (Uses .pteroext v2)

Theme Installation Guide

Deploy any MIRAINOVA theme in seconds using the native Pterodactyl v2 Artisan CLI—no manual frontend rebuild or Node compilation required on your server.

01 // DOWNLOAD PACKAGE Download your preferred .pteroext archive from the Editions catalog above.
02 // UPLOAD TO SERVER Transfer the file to your VPS via SFTP/SCP or clone the GitHub repository.
03 // INSTALL EXTENSION Run php artisan p:extension:install inside your Pterodactyl directory.
04 // ACTIVATE THEME Activate via CLI p:theme:activate or through Admin → Themes in the web UI.
BASH // /var/www/pterodactyl 
# 1. Navigate to your Pterodactyl v2 root directory
cd /var/www/pterodactyl

# 2. Install the theme package (.pteroext)
php artisan p:extension:install /root/ada-wong-ui-1.1.0.pteroext

# 3. Activate the theme (options: ada-wong-ui | shorekeeper-ui | luna-bliss-ui | mirai-glassmo)
php artisan p:theme:activate ada-wong-ui

# 4. Clear view & config caches if needed
php artisan view:clear && php artisan config:clear
