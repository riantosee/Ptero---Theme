Apakah Support Pterodactyl Versi Sebelumnya (v1.x)?

TIDAK SUPPORT PTERODACTYL v1.x (v1.11.x KE BAWAH).
Seluruh tema MIRAINOVA dibangun khusus di atas Pterodactyl Extension & Theme System v2 (format .pteroext dan Tailwind CSS v4). Panel versi lama (v1.x) menggunakan struktur Blade monolitik + Webpack/Laravel Mix dan tidak memiliki perintah php artisan p:extension:install maupun fitur hot-swap theme.

Panduan Instalasi Theme

Proses pemasangan dilakukan langsung melalui CLI artisan Pterodactyl v2 dalam hitungan detik tanpa perlu rebuild aset frontend secara manual.

01 // UNDUH PAKET Unduh file .pteroext dari katalog Ediciones di atas.
02 // UPLOAD KE VPS Unggah file ke direktori server VPS Anda melalui SFTP/SCP.
03 // INSTALL EKSTENSI Jalankan p:extension:install pada folder Pterodactyl.
04 // AKTIFKAN THEME Aktifkan via CLI p:theme:activate atau menu Admin → Themes.
BASH // /var/www/pterodactyl 
# 1. Masuk ke direktori instalasi Pterodactyl v2
cd /var/www/pterodactyl

# 2. Pasang paket ekstensi tema (.pteroext)
php artisan p:extension:install /root/ada-wong-ui-1.1.0.pteroext

# 3. Aktifkan tema (pilihan: ada-wong-ui | shorekeeper-ui | luna-bliss-ui | mirai-glassmo)
php artisan p:theme:activate ada-wong-ui

# 4. Bersihkan cache jika diperlukan
php artisan view:clear && php artisan config:clear
